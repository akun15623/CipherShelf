# Secure Vault 🔐 保险箱

一个自托管的密码保险箱：输密码后在网页里查看/上传/预览/播放加密文件；磁盘上全是密文，没有密码谁也读不了。

## 核心特性

- **AES-256-GCM 加密**：每个文件独立随机密钥，密码经 PBKDF2-SHA256（60 万次迭代）派生主密钥
- **分块加密 + HTTP Range**：大文件（视频/音频）按 1MB 分块，支持拖进度条、流式播放
- **文件名/MIME 也加密**：外面看不到文件名和类型（防元数据泄露）
- **加密缩略图**：图片宫格显示缩略图，缩略图同样加密落盘，外部不可见
- **多层级目录**：无限嵌套文件夹树，文件夹可新建/重命名/移动/复制/删除（防循环）
- **批量勾选操作**：勾选多个文件/文件夹，一键删除、移动、复制、下载（下载打包为 zip）
- **加密已有文件**：把 NAS 上已有的明文文件放进导入目录，网页一键加密进保险箱
- **离线解密**：提供 `decrypt.py`，只要密码 + 数据目录就能还原全部明文，不依赖前端服务
- **横屏预览**：图片/视频全屏预览，横屏自适应，上下/左右滑切换
- **移动端适配**：≤768px 抽屉式侧边栏 + 汉堡菜单
- **密码唯一钥匙**：密码不落盘、不进日志、无找回后门；忘密码 = 数据永久不可读
- **自动锁定**：默认 30 分钟无操作自动锁定（可配 `AUTO_LOCK_SECONDS`）

## 威胁模型（防什么 / 不防什么）

- ✅ 防：硬盘/整机被拿走直接读 → 磁盘全是密文
- ✅ 防：文件被单独拷走 → 密文 + 文件名也是密文
- ✅ 防：外人无密码访问 → 401，无法读取
- ❌ 不防：服务器 root 在**解锁状态**下读进程内存（在线预览的必然代价）

若需要"连服务器管理员都看不了"，请改用端到端加密方案（如 Cryptomator），
但会失去网页在线预览/流式播放能力。

## 快速开始

```bash
docker compose up -d --build
```

首次访问 `http://<服务器IP>:6070` → 设置密码 → 进入保险箱。

## 加密已有文件（导入）

1. 把要加密的明文文件放进 `./import/` 目录（`docker compose` 默认挂载了它）
2. 网页里点右上角「导入」→ 勾选文件 → 「加密到保险箱」
3. 可选勾选「加密后删除原文件」，加密完成后删掉 NAS 上的明文
4. 子目录结构会保留（自动创建对应文件夹）

## 离线解密（应急恢复）

即使前端服务/容器丢失，只要数据目录还在，就能用密码把文件全部还原：

```bash
# 在数据目录所在机器上（含 crypto.py）
python3 decrypt.py --data-dir /path/to/vault-data --output /path/to/restored

# 只想看清单（不解密）
python3 decrypt.py --data-dir /path/to/vault-data --list
```

密码用交互式输入，不回显、不落盘、不进日志。仅依赖 `cryptography` 库。

## 配置（环境变量）

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `VAULT_DATA_DIR` | `/data` | 加密数据目录（含 vault.db + files/） |
| `VAULT_IMPORT_DIR` | `/import` | 导入目录（放待加密的明文文件） |
| `AUTO_LOCK_SECONDS` | `1800` | 自动锁定秒数，`0` 关闭 |
| `MAX_UPLOAD_MB` | `4096` | 单文件上传上限 |

## 数据目录结构

```
/data/
  vault.db            # SQLite：盐、验证器、加密的文件元数据（无明文名、无密钥）
  files/
    <id>.enc          # 加密文件
    <id>.thumb.enc    # 加密缩略图
  tmp/                # 上传/下载临时文件（用完即删）
```

## 技术栈

- 后端：FastAPI + SQLite + cryptography + Pillow
- 前端：Vue 3 + Element Plus（本地托管，无外部 CDN、无构建）
- 部署：Docker

## ⚠️ 重要提醒

1. **密码没有找回功能**。请务必记住密码，或把密码存在独立的安全位置（如密码管理器）。
2. 建议通过 **HTTPS** 访问（cpolar 隧道 / 反向代理），否则密码在局域网内是明文传输。
3. 首次部署前，`vault-data/` 目录会被自动创建，请勿删除（删除 = 数据丢失）。
4. 「加密后删除原文件」删除的是导入目录里的明文副本，不是安全擦除（SSD/机械盘可用文件恢复工具找回痕迹）；对极敏感文件请额外做全盘加密。
