# Secure Vault 🔐 文件夹就地加解密工具

一个自托管的文件夹加解密工具：**一个密码 = 一个密钥**，就地加密文件夹（文件内容加密、目录名/文件名变密文、结构保留），解密时凭密码 + 索引还原。

## 核心特性

- **单密钥**：密码经 PBKDF2-HMAC-SHA256（60 万次迭代，固定 salt）派生一个主密钥，所有文件都用它加解密
- **就地加密**：选一个文件夹，里面每个文件原地变密文、名字变乱码，目录结构保留
- **加密索引 `.svault`**：记录「原名 ↔ 密文」映射，整体用主密钥 AES-GCM 加密，没有密码看不到任何结构
- **流式分块**：AES-256-GCM 按 1 MiB 分块，大文件（GB 级）不占内存
- **Web 界面**：进入输密码 → 文件夹树多选 → 加密/解密按钮 → 实时进度条；已加密内容显示原文件名 + 🔒
- **CLI**：`encrypt.py` / `decrypt.py`，与 Web 共用同一套加密核心，可互换
- **PC + 移动端**：响应式上下结构（上树 + 下按钮）

## 快速开始

```bash
docker compose up -d --build
```

访问 `http://<服务器IP>:6070` → 输入密码 → 进入。

> 默认把宿主 `/vol1/1000/appData` 挂到容器 `/data`（`VAULT_ROOT`）。
> 按需修改 `docker-compose.yml` 的 volumes，挂载你要操作的目录。

## Web 使用

> 若配置了 `VAULT_PASSWORD` 环境变量：访问时直接输入该预设密码即可进入（跳过下面的「创建密码」步骤）。

1. **首次使用**：显示「创建密码 + 再次确认密码」，设置 ≥ 8 位密码（即密钥，**务必记住**）；第一次成功加密后才正式建立，此前锁定/重启可重新设置
2. **之后进入**：只需输密码解锁，错误密码提示「密码错误或索引损坏」
3. 文件夹树展开、勾选要加密的目录
4. 点「🔒 加密选中」→ 就地加密（结构保留、名字变密文、生成 `.svault`）
5. 已加密目录显示原文件名 + 🔒
6. 勾选已加密目录 → 点「🔓 解密选中」→ 还原

## CLI 使用

```bash
# 加密（密码交互输入，不回显）
python3 encrypt.py /data/照片

# 解密（就地还原；或 -o 输出到别处）
python3 decrypt.py /data/照片
python3 decrypt.py /data/照片 -o /restore/照片

# 可选参数
--password <pwd>    # 明文密码（不推荐，会留 shell 历史；缺省交互）
--iterations <n>    # PBKDF2 迭代次数（默认 600000）
--yes               # 跳过确认
```

## 加密格式

```
加密前  /data/照片/
          ├── 2024/旅行.jpg
          └── 2025/视频.mp4

加密后  /data/照片/               ← 根名保留（操作锚点）
          ├── .svault             ← 加密索引
          ├── 9f3a2c7e.../        ← 「2024」→ 密文目录名
          │   └── c7e2f0a9...     ← 「旅行.jpg」→ 密文（无扩展名）
          └── a3d6b8f1.../        ← 「2025」
              └── 5e9c2b7a...     ← 「视频.mp4」
```

- 密文名 = 32 位随机 hex，无扩展名、无原名字符
- 结构保留：子目录层级不变，只是名字变密文

## 配置（环境变量）

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `VAULT_ROOT` | `/data` | 加解密操作的根目录 |
| `PORT` | `8080` | 服务端口 |
| `VAULT_PASSWORD` | （未设置） | 可选：预设初始密码。设了之后访问时输入它即可进入（不再显示「创建密码」两步）；不设则保持首次「创建密码 + 确认」流程 |

> ⚠️ `VAULT_PASSWORD` 会以明文形式保存在 compose 文件 / 容器环境里，任何能 `docker inspect` 或读 compose 文件的人都能看到。请确保文件权限（如 `chmod 600`）、不要把 `.env` 提交进版本库。改这个值 = 换密钥，旧密码加密的数据将无法解密。

## 技术栈

- 后端：FastAPI + cryptography（AES-256-GCM + PBKDF2）
- 前端：Vue 3 + Element Plus（本地托管，无 CDN、无构建）
- 部署：Docker

## 重新部署与数据恢复

密码和主密钥**不落盘**（不写数据库/配置/Cookie/索引，只存在进程内存）。重新部署时：

- 完整保留数据目录（密文文件 + `.svault`，含隐藏文件），并把它挂到新容器的 `VAULT_ROOT`；
- 输入**原密码**即可重新派生同一主密钥并解密所有数据；
- 忘记密码 / 丢失 `.svault` / 改动固定 salt，都会导致数据不可恢复。

## ⚠️ 重要提醒

1. **密码没有找回功能**。忘记密码 = 已加密文件永久不可读。
2. **固定 salt**：同一密码永远派生同一密钥（「都用一个密钥」的心智代价——用同一密码的人能互相解密）。请使用强密码（≥ 8 位，建议更长）。
3. **备份 `.svault`**：索引是还原的关键，损坏则目录无法还原，请妥善备份。
4. **加密后原明文会被删除**（就地加密），加密前请确认无其他需要。
5. 建议通过 **HTTPS** 访问，否则密码在局域网内是明文传输。
